# StudyPlan

複数の資格試験の計画と進捗を、この端末だけで管理する日本語デスクトップアプリです。

ホームから「今日のスケジュール」→「今日の進捗を記録」の順に操作できます。カレンダーの表示密度は「コンパクト・標準・詳細」から選べます。月はコンパクト、週・一覧は標準が初期値で、表示ごとの選択を保存します。

今日の進捗をアニメーション付きで確認できます。「通学時間」で往復の時間を設定でき、授業や予定との重複を除いて学習枠から差し引きます。警告は開閉・無視でき、「警告の管理」から戻せます。サイドバー右端の◀／▶で開閉し、狭い画面でも使えます。

ホームには通学の往路・復路・合計を表示し、食事に重なった復路も隠しません。時刻の内訳は学習・休憩をまとめて表示します。授業間の10分以下は移動として学習枠から除外します。既存計画への反映は再計画案を承認してから行います。

初期設定は一問ずつ進めます。入力途中も保存されます。複数試験の共通計画、選択式の進捗、履歴の訂正・取消、再計画の提案・承認・復元に対応します。

数値は空欄にして入力し直せます。対話の質問ではEnter1回で検証して次へ進み、「次へ」のクリックでも入力を確定できます。任意問題数の進捗は入力後に「記録する」を押すか、Enter1回で登録できます。授業は「学習不可」と表示し、時間割の下で除外後の学習枠を確認できます。計画案には設定日時・一日の問題数・余裕率0%での参考終了日を表示します。左側のカラーテーマで緑・薄い青・ライムを選べます。

再計画は「再計画の確認 → 対話で条件を見直す」から、現在の設定を読み込んで一問ずつ修正できます。回答は下書き保存し、設定と計画は案を承認してから更新します。カレンダーには授業と学習予定を時刻順に表示し、現在の授業と重なる古い学習予定には警告を出します。時刻は計画上の開始・終了で、学習可能枠は予定を入れてよい範囲です。

1日の可処分時間を見えるようにすることも、このプロジェクトの目標です。朝・昼・夜の食事を30〜60分ずつ、開始時刻から対話で設定できます。ホームとカレンダー下の時間の内訳で、登録した学習可能枠から食事・授業・予定を除いた可処分時間と休憩を確認できます。余裕率は週全体の割当上限にだけ適用し、日ごとの余裕時間は予約しません。カレンダーの予定カードは勉強と大学の授業だけを表示します。

集中量は日次の総量ではなく「連続で勉強できる最長時間 → 休憩 → 次の勉強」で計算します。既存の1ブロックの長さを引き継ぎ、古い日次上限は使いません。以前の計画は保持し、再計画の承認後に新方式の計画へ切り替えます。

サイドバーの「今日のスケジュール」から、その日の勉強と大学の授業を直接確認・記録できます。授業名は任意で入力できます。「対話式の初期設定 → 設定項目を選んで修正する」から既存の試験・教材・時間割などを選び直せます。

授業名の欄は曜日・時刻順です。「学習カレンダー → ICSを書き出す」では、期間を指定し、学習予定と授業（授業名付き）を選択して保存できます。学習は承認済みの計画を使います。書き出した予定は自動更新されません。

「週間レポート → 対象の週を選ぶ → Markdownを保存」で、週の予定・記録と全体進捗を比較した `.md` を書き出せます。試験別・教材の周回別・日別の内訳、0問報告と未報告を含みます。過去の週を選んだ場合も、全体進捗は出力時点の値です。

再計画の固定エラーには、授業との重複・休憩・余裕率などの原因を表示します。「条件を修正」で該当する質問へ移動し、「固定を解除して案を更新」で対象だけ解除できます。予定時刻の変更は承認してから反映します。

承認・破棄ボタンを再計画画面の上部に置き、同じ場所に承認できない理由と確認・修正ボタンを表示します。未報告の確認や競合の説明へ直接移動でき、確認後は承認操作へ戻れます。

計画は問題数ではなく、教材・周回ごとの推定時間でまとめます。60分なら短答3分×20問、論文30分×2問が入ります。通常の下限は10分、目安は30分で、設定から変更できます。短い端数は統合・繰り越しを試み、完了時や期限上必要な場合だけ例外にします。問題数による一律の下限や5問刻みの丸めはありません。

初期設定の初期化は警告と確認チェック付きです。「質問の進行だけ」と「設定・計画・記録の全体」を選べます。全体の初期化直前のデータは端末内に1世代保存し、再起動後も復元できます。

## 起動

使い方はサイドバーの「チュートリアル」に分けています。初期設定・時間・計画・記録・再計画・保存の6項目から必要な項目だけ読めます。通常の画面には入力と操作、必要な注意を残しています。

「バックアップ」から設定・計画・実績・入力途中を `.studyplan.json` に保存できます。復元は内容の確認後に全体を置き換え、直前の状態に1回分戻せます。

ビルド済みの `release/StudyPlan.exe` をダブルクリックしてください。Windows + Microsoft Edge WebView2 Runtimeが必要です。ブラウザーからの起動や外部アカウントは不要です。

2026-09-21の v0.4.8 は `release/StudyPlan.exe` と `release/StudyPlan-20260921.exe`（同じ内容）。今日の進捗・警告の管理・サイドバー折りたたみ・可変幅・通学時間を追加しました。進捗の円グラフ、16色の試験色、ライト・ダーク・システム表示を追加しました。画面・HTMLタイトル・ウィンドウ名のアプリ表記を「StudyPlan」に統一しました。承認ボタンを上部へ移し、ホームの装飾メッセージを削除しました。学習枠の未登録期間と長期計画の見直し警告を追加しました。警告から時間枠・周回数・目標日を対話で修正できます。試験・教材の対話式追加、承認の案内、週の表示整理、データを引き継ぐ更新パッケージも含みます。週間レポート・ICS・3配色の改善も含みます。保存先は共通なので、切り替える際は今のStudyPlanを閉じてから新しいファイルを開いてください。

データの保存先は通常 `%APPDATA%\jp.local.studyplan\studyplan.sqlite3`。開発用テストデータは別フォルダーに分離します。保存中にウィンドウを閉じた場合は、最後の入力の保存を待ってから終了します。保存に失敗した場合は終了を中止して知らせます。強制終了や電源断はこの待機の対象外です。

起動時に保存データを開けない場合は「もう一度読み込む」で再試行できます。原因と保存先は「エラーの詳細」に表示します。読めないデータを自動で初期化することはありません。

操作中の保存と再読み込みの両方が失敗した場合は「保存未確認」と表示し、編集を止めます。「保存済みの内容を読み直す」で復帰でき、反映されていない変更は入力し直せます。確認できないまま終了する場合は、未保存の変更が失われることを確認してから閉じます。

## 開発

必要環境: Node.js 22.13以降の22系または24以降、pnpm、Rust stable、Visual Studio C++ Build Tools、Windows SDK、WebView2 Runtime。

```powershell
pnpm install
pnpm desktop
```

`pnpm dev`だけではWeb画面のみで、保存処理にはTauriが必要です。通常利用はデスクトップ版を起動してください。

開発画面で `ERR_CONNECTION_REFUSED` が出た場合は開発サーバーの停止を確認してください。監視対象からRustのビルド出力・配布物・テスト出力を除外し、Windowsで実行ファイルのロックによってサーバーが停止する問題を防いでいます。配布版は開発サーバーに依存しません。

```powershell
pnpm test
pnpm lint
pnpm typecheck
cargo test --manifest-path src-tauri/Cargo.toml
pnpm build
cargo build --manifest-path src-tauri/Cargo.toml
pnpm test:ui
pnpm desktop:build
```

`pnpm test:ui` はWindows上の**実際のTauri + WebView2ウィンドウ**をPlaywrightで操作します。検証用SQLiteを`.test-data/native-*`に作り、デバッグ接続のポート9223を使います。通常の保存領域には触れません。画面を確認するためのスクリーンショットは`test-results/`に出力します。

WebView2の画面データも起動ごとに `.test-data/native-webview-*` へ分離します。配布版の読み取り専用起動確認は `node scripts/release-smoke.mjs [実行ファイルのパス]`。指定を省くと `release/StudyPlan.exe` を確認します。

`pnpm desktop:build` の出力は `src-tauri/target/release/studyplan.exe`。インストーラーは生成しません。

## 実装の構成

| 場所                           | 内容                                                 |
| ------------------------------ | ---------------------------------------------------- |
| `src/domain/`                  | UIから独立した型、時間枠計算、計画、記録、承認・復元 |
| `src/app/`                     | 画面の組み立て、外枠、ナビゲーション                 |
| `src/hooks/`                   | 保存・読込・競合・復旧と終了待ち                     |
| `src/components/guided-setup/` | 一問ずつ進む設定画面、質問モデルと純粋な遷移         |
| `src/components/setup/`        | 試験・教材・時間枠・集中・余裕率の一覧編集           |
| `src/domain/planner/`          | UIと保存から独立した純粋な計画計算・制約・提案       |
| `src/components/`              | 一覧編集、カレンダー、進捗、履歴、再計画             |
| `src/store.ts`                 | Tauriの保存コマンドとの境界                          |
| `src-tauri/src/db.rs`          | SQLite、リビジョン制御、重複防止、検証、監査履歴     |
| `tests/`                       | 計算・状態遷移の単体テストとWindows実機E2E           |

責任の境界と依存関係は[アーキテクチャ](docs/ARCHITECTURE.md)を参照してください。

詳細は[実装仕様](docs/SPEC.md)と[動作確認記録](docs/VALIDATION.md)を参照してください。

[実利用フローの監査](docs/REAL_USE_AUDIT.md)には、架空の学生データ、見つかった不整合と修正、確認範囲と残る制約を記録しています。

計画は制約を守る分散型のヒューリスティックです。数学的な最適解は保証しません。入らない課題は不足として表示し、連続学習の長さや余裕率を自動変更しません。

## 試験・教材を追加する

ホームまたは一覧の「試験を追加」「教材を追加」から、一問ずつ登録できます。途中で中断しても一覧の再開ボタンで続けられます。

登録後は「追加・変更を含めた計画案を確認」から内容を確認し、承認するとカレンダーが更新されます。案を破棄しても登録した試験・教材は残ります。承認前は現在の計画が維持されます。

## 更新パッケージ

`release/StudyPlan-update-0.4.8.zip` を展開し、`Update.cmd` を開いて、これまで使っていた StudyPlan の実行ファイルを選んでください。アプリを閉じてから行います。設定・計画・記録は同じ保存先を引き継ぎます。旧実行ファイルも控えとして残します。

実行ファイル全体を差し替える更新パッケージです。差分ダウンロードや自動更新は行いません。手動で同梱の `StudyPlan.exe` を差し替えても更新できます。

開発時は各版の番号を更新して `pnpm desktop:build` の後、`./scripts/package-update.ps1` を実行すると、その版の更新ZIPを作成できます。

## Git管理

リポジトリは https://github.com/akagii-dev/studyplan 。ソース・テスト・仕様書と依存関係のロックファイルを管理します。

SQLiteの保存データ、`.studyplan.json` バックアップ、`.env`、実行ファイル・更新ZIP、ログ、テスト用データ、依存パッケージとビルド出力はGitへ含めません。`release/` はローカルで作成する配布物です。リポジトリを取得した環境では、開発の手順でビルドしてください。

## v0.4.4 の変更

往路・復路それぞれの出発時刻と所要時間を対話で確認します。食事と重なる場合は修正を案内し、食事を自動で移動しません。一括スキップボタンを削除し、サイドバー開閉レールを12pxにしました。旧設定で授業から自動計算していた出発時刻は、通学設定で再確認してください。既存の計画へ新しい計算を反映するには、再計画案を確認して承認してください。

## v0.4.5 の変更

「1日の可処分時間」を、学習可能量・配分バー・簡潔な凡例・折りたたみ詳細に整理しました。往復の通学時刻は詳細で確認できます。修正が必要な警告はそのまま表示します。計算・保存データは変更しません。全テーマ、キーボード操作、文字拡大と狭い表示の検証結果は [VALIDATION.md](docs/VALIDATION.md) を参照してください。

## v0.4.6 の変更

「1日の可処分時間」の配分バーをドーナツ型の円グラフへ変更しました。広い画面では主指標・円グラフ・凡例を横に、狭い画面では縦に配置します。説明文は追加せず、計算・保存・詳細・警告は維持します。

## v0.4.7 の変更

円グラフの通学・食事を一つの区分と凡例にまとめ、睡眠の色を控えめにしました。詳細の分類名に対応色の下線を付けました。初期設定に任意の睡眠・風呂を追加しました。設定項目から再編集でき、学習対象外・未設定の部分だけを細分化して表示します。学習計画の計算は変わりません。

## v0.4.8 の変更

円の中心に学習可能時間を表示し、外側の主指標と凡例の重複を削除しました。円グラフと内訳を2列に整理し、狭い幅では縦に並べます。文字拡大で円内へ収まらない場合は、値を円の直下へ移して重なりを防ぎます。計算・保存データは変更しません。

Windows版と更新用ZIPは [GitHub Releases](https://github.com/akagii-dev/studyplan/releases/tag/v0.4.8) から取得できます。
