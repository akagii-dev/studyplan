# StudyPlan

複数の資格試験の学習予定と実績を、この端末で管理する日本語アプリです。

公開デモ：[StudyPlanをブラウザーで試す](https://akagii-dev.github.io/studyplan/)。初めて開くと、架空の試験・問題集・学習時間と計算済みの予定が入っています。既に保存したデモデータは上書きしません。

公開デモの入力はブラウザー内に保存され、デスクトップ版のSQLiteデータとは共有されません。デモではバックアップと書き出しを利用できません。

## 毎日の使い方

1. 「今日」で問題集・周回ごとの予定問数を確認します。復習予定もここに表示されます。
2. 同じ行に実際の追加問数を入力し、「記録」を押します。0問も明示的な実績として記録できます。予定外の学習は「予定外の学習を記録」から入力します。
3. 保存が完了すると、実績を基に残量を計算し、明日以降の学習可能枠へ自動配分します。「今後の予定」で日別の結果を確認できます。

実績は「記録履歴」から訂正・取消できます。訂正後も明日以降を再計算します。今日以前の予定と実績、固定予定は保持します。条件に収まらない量は「未配置」に教材・周回別の理由とともに残します。固定予定の競合、未承認の設定案、設定と計画の不一致があるときは実績だけを保存し、計画案の確認へ進めます。

主画面は「今日」「今後の予定」「記録履歴」「設定」です。時刻や固定予定は詳細カレンダー、試験・教材・時間枠・通学・レポート・バックアップ等は「設定」から開けます。設定変更と手動の再計画案は承認してから反映します。

## 起動

使い方は「設定」→「使い方」に分けています。初期設定・時間・計画・記録・再計画・保存の6項目から必要な項目だけ読めます。通常の画面には入力と操作、必要な注意を残しています。

「バックアップ」から設定・計画・実績・入力途中を `.studyplan.json` に保存できます。復元は内容の確認後に全体を置き換え、直前の状態に1回分戻せます。

[最新版 v0.4.20](https://github.com/akagii-dev/studyplan/releases/tag/v0.4.20)のWindows版をダウンロードして起動してください。Windows + Microsoft Edge WebView2 Runtimeが必要です。外部アカウントは不要です。旧版と保存先は共通なので、版を切り替える際は起動中のStudyPlanを閉じてください。

データの保存先は通常 `%APPDATA%\jp.local.studyplan\studyplan.sqlite3`。開発用テストデータは別フォルダーに分離します。保存中にウィンドウを閉じた場合は、最後の入力の保存を待ってから終了します。保存に失敗した場合は終了を中止して知らせます。強制終了や電源断はこの待機の対象外です。

起動時に保存データを開けない場合は「もう一度読み込む」で再試行できます。原因と保存先は「エラーの詳細」に表示します。読めないデータを自動で初期化することはありません。

操作中の保存と再読み込みの両方が失敗した場合は「保存未確認」と表示し、編集を止めます。「保存済みの内容を読み直す」で復帰でき、反映されていない変更は入力し直せます。確認できないまま終了する場合は、未保存の変更が失われることを確認してから閉じます。

## 開発

必要環境: Node.js 22.13以降の22系または24以降、pnpm、Rust stable、Visual Studio C++ Build Tools、Windows SDK、WebView2 Runtime。

```powershell
pnpm install
pnpm desktop
```

`pnpm dev`だけではWeb画面のみで、保存処理にはTauriが必要です。通常利用はデスクトップ版を起動してください。

開発画面で `ERR_CONNECTION_REFUSED` が出た場合は開発サーバーの停止を確認してください。監視対象からRustのビルド出力・配布物・テスト出力を除外し、Windowsで実行ファイルのロックによってサーバーが停止する問題を防いでいます。配布版は開発サーバーに依存しません。

```powershell
pnpm verify
pnpm exec playwright install chromium
pnpm verify:ui
cargo test --manifest-path src-tauri/Cargo.toml
cargo build --manifest-path src-tauri/Cargo.toml
pnpm test:ui
pnpm desktop:build
```

UI・進捗変更の契約と検証範囲は[プロダクト契約](docs/ARCHITECTURE.md#進捗と画面の契約)を参照してください。`verify` はlint・型検査・単体テスト・通常ビルド、`verify:ui` は隔離ブラウザーでの画面横断検証です。ブラウザー検証はWindows/Tauriなしでも実行できます。

`pnpm test:ui` はWindows上の**実際のTauri + WebView2ウィンドウ**をPlaywrightで操作します。検証用SQLiteを`.test-data/native-*`に作り、デバッグ接続のポート9223を使います。通常の保存領域には触れません。画面を確認するためのスクリーンショットは`test-results/`に出力します。

WebView2の画面データも起動ごとに `.test-data/native-webview-*` へ分離します。`STUDYPLAN_TEST_DATA_DIR`はdebugビルド専用です。配布版の`scripts/release-smoke.mjs`は、別のWindowsテストアカウントで`STUDYPLAN_ISOLATED_WINDOWS_PROFILE=1`を指定した場合のみ実行できます。通常アカウントでは実行しないでください。

`pnpm desktop:build` の出力は `src-tauri/target/release/studyplan.exe`。インストーラーは生成しません。

## 実装の構成

| 場所                           | 内容                                                 |
| ------------------------------ | ---------------------------------------------------- |
| `src/domain/`                  | UIから独立した型、時間枠計算、計画、記録、承認・復元 |
| `src/app/`                     | 画面の組み立て、外枠、ナビゲーション                 |
| `src/hooks/`                   | 保存・読込・競合・復旧と終了待ち                     |
| `src/components/guided-setup/` | 一問ずつ進む設定画面、質問モデルと純粋な遷移         |
| `src/components/setup/`        | 試験・教材・時間枠・集中・余裕率の一覧編集           |
| `src/domain/planner/`          | UIと保存から独立した純粋な計画計算・制約・提案       |
| `src/components/`              | 一覧編集、カレンダー、進捗、履歴、再計画             |
| `src/store.ts`                 | Tauriの保存コマンドとの境界                          |
| `src-tauri/src/db.rs`          | SQLite、リビジョン制御、重複防止、検証、監査履歴     |
| `tests/`                       | 計算・状態遷移の単体テストとWindows実機E2E           |

責任の境界と依存関係は[アーキテクチャ](docs/ARCHITECTURE.md)を参照してください。

詳細は[実装仕様](docs/SPEC.md)と[動作確認記録](docs/VALIDATION.md)を参照してください。

今回の再設計の入力・計算・保存の検証は[再設計の検証記録](docs/ui-redesign-verification.md)、独立した操作評価は[UI/UX再評価](docs/ux-after-review.md)にまとめています。

[実利用フローの監査](docs/REAL_USE_AUDIT.md)には、架空の学生データ、見つかった不整合と修正、確認範囲と残る制約を記録しています。

計画は制約を守る分散型のヒューリスティックです。数学的な最適解は保証しません。入らない課題は不足として表示し、連続学習の長さや余裕率を自動変更しません。

## 試験・教材を追加する

「設定」の基本設定から試験・教材を直接追加できます。途中で中断しても一覧の再開ボタンで続けられます。

登録後は「追加・変更を含めた計画案を確認」から内容を確認し、承認するとカレンダーが更新されます。案を破棄しても登録した試験・教材は残ります。承認前は現在の計画が維持されます。

## 更新パッケージ

`release/StudyPlan-update-0.4.20.zip` を展開し、`Update-StudyPlan.ps1` を右クリックして「PowerShellで実行」を選び、これまで使っていた StudyPlan の実行ファイルを選んでください。アプリを閉じてから行います。設定・計画・記録は同じ保存先を引き継ぎます。旧実行ファイルも控えとして残します。

実行ファイル全体を差し替える更新パッケージです。差分ダウンロードや自動更新は行いません。手動で同梱の `StudyPlan.exe` を差し替えても更新できます。

開発時は各版の番号を更新して `pnpm desktop:build` の後、`./scripts/package-update.ps1` を実行すると、その版の更新ZIPを作成できます。以降の配布にはCMDランチャーと独立したSHA256SUMSを含めません。更新処理内部の破損検証は維持します。詳しくは[リリース手順](docs/RELEASING.md)を参照してください。

## Git管理

リポジトリは https://github.com/akagii-dev/studyplan 。ソース・テスト・仕様書と依存関係のロックファイルを管理します。

SQLiteの保存データ、`.studyplan.json` バックアップ、`.env`、実行ファイル・更新ZIP、ログ、テスト用データ、依存パッケージとビルド出力はGitへ含めません。`release/` はローカルで作成する配布物です。リポジトリを取得した環境では、開発の手順でビルドしてください。
