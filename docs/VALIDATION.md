# 動作確認記録

各版の検証の要点と、まだ確認できていないことを残す。v0.11.1以前の記録はGitの履歴（`git log -p -- docs/VALIDATION.md`）を参照。

## 検証の方法

- `pnpm verify`：lint・型検査・単体テスト・通常ビルド。
- `pnpm verify:ui`：デモをビルドし、隔離ブラウザーで画面横断テストとカレンダー部品テストを行う（Windowsでは`PLAYWRIGHT_CHANNEL=msedge`）。SQLiteや保存ダイアログの実機試験の代わりにはならない。
- `pnpm test:ui`：Windows/Tauriの実機テスト。専用SQLite（`.test-data/`）だけを使う。
- `pnpm verify:lan`：LAN版を専用DBとデバッグブリッジで確かめる。

## まだ確認できていないこと

- iPhone実機のSafari・ホーム画面、別の端末からのLAN接続。
- 配布インストーラーのインストール・起動（隔離したWindowsアカウントがないため）。
- スクリーンリーダーでの読み上げ。
