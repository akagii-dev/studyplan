# StudyPlan v0.4.15

- 「今日」に問題集ごとの予定と実績入力を並べました。実績の記録・訂正・取消から、明日以降の未実施分を自動で再配分します。固定済みの予定、過去の予定と実績は保持し、入りきらない量は未配置として示します。
- 設定画面では、必須の試験・教材・学習時間を直接操作できる3行へ整理しました。補足条件は必要なときだけ開けます。未登録、入力不備、保存・読込失敗は区別して表示します。
- 狭い画面の下部ナビゲーションを整え、アイコンと文字を中央に揃えました。
- 公開デモを初めて開くと、架空のサンプル試験・問題集・学習時間と計算済みの予定が表示されます。既にブラウザーへ保存したデモデータは変更しません。

Windows版は `StudyPlan-0.4.15.exe` をダウンロードして起動できます。旧版からの更新には `StudyPlan-update-0.4.15.zip` を展開し、同梱の `Update.cmd` を使用してください。既存の設定・計画・記録は同じ保存先を引き継ぎます。配布ファイルの SHA-256 は `SHA256SUMS.txt` にあります。

検証：単体テスト284件、デスクトップ実機E2E37件、型検査、Lint、Windows配布版の起動・終了、デモのPC/390px幅での初期表示と保存に成功しました。設定画面は独立したUI評価で再確認しています。
