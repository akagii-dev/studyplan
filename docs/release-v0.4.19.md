# StudyPlan v0.4.19

- 一部だけ記録した日の残りを二重に予定へ入れず、変更不要な教材の配置を維持します。
- 自動調整の変更を、数量と配置に分けて表示します。
- 今日・今後の予定・カレンダー・週間レポートの進捗表示を揃えました。未報告と0問記録を区別します。
- 今日の教材別の進捗を小さな円で表示し、日付詳細から対象の記録欄へ移動できます。
- 週間レポートは過去の保存済み予定を参照し、異なる単位を分けて集計します。

Windows版は `StudyPlan-0.4.19.exe`、旧版からの更新は `StudyPlan-update-0.4.19.zip` をご利用ください。
