# StudyPlan v0.6.0

- Windowsアプリの「設定」からLAN公開を開始・停止できます。同じWi-FiのiPhoneで、Windowsと同じ予定・実績を扱えます。
- 接続リンクとAPIキー、共有時の注意を表示します。HTTPは暗号化されないため、信頼できる個人LANで使用してください。アプリ終了で公開が停止します。
- 日付を越えた未消化分を自動調整し、「計画を仕切り直す」で残りを指定日から組み直せます。
- スマホ下部ナビの選択表示を下側へ移しました。
- 警告の「閉じる」ボタンを本文の下へ移しました。

初めて使う場合はEXE、既存版の差し替えには更新ZIPをご利用ください。更新前にバックアップを保存し、起動中のStudyPlanと旧LANホストを終了してください。保存先は従来と共通です。
