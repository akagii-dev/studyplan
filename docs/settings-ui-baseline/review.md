## 所見

1. **MEDIUM / Layout・効率** — 設定へ入った直後、最初に行う「初期設定」や試験・教材・時間枠の設定入口が、必須警告3枚と通知4枚の下にある。必須の未入力状態ほど入口が遠くなり、警告文を読んでスクロールしないと設定を始められない。警告文は「試験・目標で登録」等の移動先を示すが、文そのものは操作ではない。今日の空状態には「設定を始める」の直接ボタンがあり、そこから初期設定へは1操作で行けるが、設定画面の各編集入口は埋もれている。
2. **MEDIUM / Writing・判断負担** — 必須3枚がそれぞれ「計画を作成できません」と理由・操作先を説明し、補足4枚も展開状態で長い説明を出す。最初の表示範囲に設定操作がなく、主目的である設定開始より条件の読解が先になる。必須項目を隠すべきではないが、同じ未設定事実と移動先を短い操作に集約できる。
3. **LOW / Writing** — 補足通知の「無視する」は「今回閉じる」のか「その項目を確認済みにする」のか、押す前には分からない。実操作では食事通知だけが消え、必須未入力は変わらず、再読込後も食事通知は非表示だった。設定内容自体を消していないことは確認できたが、永続的に隠れる結果はボタン名から読み取りにくい。

これらは見た目の好みではなく、設定入口までのスクロールと読み取り、通知操作の結果に基づく。必須警告の存在自体と、補足の確認が必要なことは問題として扱わない。
