## Verification

- 実行：`pnpm demo:preview`（サンドボックス外で起動）と `node test-results/ux-baseline/ux-baseline-main.mjs`。Edge の独立 context で今日の予定→5問記録→計画案承認→月カレンダーの翌日15問まで操作した。
- 実測：1280px で記録前の実績「未入力」、記録後5問、計画案の翌日10→15問、反映後のカレンダー翌日15問。画面表示と操作経路の確認であり、配分エンジンの正しさの独立検証ではない。
- Axe：記録画面で violations 0件。320px では `document.documentElement.scrollWidth=430`、`innerWidth=320`。
- スクリーンショットは監査時に取得・確認したが、その後のPlaywright既定出力ディレクトリーの初期化によりファイルを失った。上記は監査時に記録した実測結果。再発防止としてデスクトップE2Eの出力先を専用サブディレクトリーへ分離し、変更後の独立評価は `docs/ux-after-eval/` に保持する。
- **Not verified**：デスクトップ実機、スクリーンリーダー、キーボードだけの全経路、200%ズーム、RTL、ダーク・他テーマ、異常系。空状態は別スクリーンショットを取得したが日常フローの合否には含めていない。

**Block** — 日常フローの再配分に追加判断が必要で、320pxでは主要操作がはみ出す。
